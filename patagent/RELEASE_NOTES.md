# PatAgent snapshot used for the review

The executable wrapper is version 0.1.0 and is copied byte for byte from the local Bio Agent Stack installation. Source hashes are in SOURCE_PROVENANCE.json. The skill and agent specification have only path/packaging edits. Run the network-free smoke test with `python3 patagent/server.py smoke-test` from the repository root.

This is an evidence-linked review aid inspired by public writings, not Pat Walters, his endorsement, or an independent scientific validator. The retained postflight checklist contains unresolved fields that are outside this released-label analysis. A passing smoke test checks software behavior only.

The historical local corpus contained 91 posts (74 Blogger, 17 GitHub Pages, including one guest post). Full blog text is not redistributed. The supplied metadata records its hash and source counts; corpus refresh failed during the review. Live retrieval can change and is not required to reproduce any reported numerical result. Optional `sync-corpus` and `search` commands use public sources and should retain attribution and respect source rights. The optional MCP server requires the separately installed `mcp` Python package; the CLI requires only Python's standard library.
